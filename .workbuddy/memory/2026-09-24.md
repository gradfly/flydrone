## Web demo 场景改造：卧室 → 泡沫垫飞行训练场（docs/live）

需求：清空三维环境内设施，改为参考图风格——蓝白灰拼色地垫地面 + 8 个随机放置的蓝白灰拼色长方体障碍物。

改动文件（均在 `docs/live/`）：
- `engine.js`：新增 `makeObstacles(seed)`（带种子的 mulberry32 随机生成 8 个 AABB 碰撞箱，尺寸 0.35–0.8m 宽、1.1–2.0m 高，避开三个起飞点、彼此保持 0.45m 间距）；`ROOM.boxes` 改为 `makeObstacles()`（每次页面加载随机布局）；`RayCamera` 视网膜渲染的地面棋盘格从 0.35m 改为 0.5m（与地垫尺寸一致）。
- `models.js`：新增 `createObstacleMesh(box)` 导出——按碰撞箱生成泡沫垫拼色长方体（横向色带堆叠，灰/浅灰/白/蓝/藏青 9 色调色板，EVA 菱形纹理 canvas，共享纹理缓存），附带霓虹描边（夜间发光/预警高亮用）。
- `room.js`：整体重写。删除地毯、窗户、窗帘、植物、海报、门、挂钟、椅子/床/衣柜、吊灯；地面换为 0.5m 蓝白灰泡沫垫棋盘（day/night 两套纹理）；白墙+踢脚线保留；新增顶部补光灯替代吊灯；`createRoom(scene, boxes)` 接收碰撞箱数组；`highlight("chair")` 替换为 `highlightNearest(simPos, level)`（高亮距无人机最近的障碍物）。
- `app.js`（最小适配）：`import { Pilot, ROOM } from "./engine.js?v=4"`；`createRoom(scene, ROOM.boxes)`（注意：app.js 用 `?v=4` 查询串引入 engine.js，room.js 若直接 import engine.js 会得到另一个模块实例导致视觉与物理布局不一致，所以由 app.js 传入）；pickables 三件家具换成 `room.obstacles`；`room.highlight("chair", loom)` → `room.highlightNearest(p, loom)`。

## 2026-09-25 补充：障碍物碰撞箱长宽固定为 0.5m

- `makeObstacles()` 重写：footprint 固定 0.5×0.5m（一块地垫尺寸），lo 角点吸附到 0.5m 地垫网格（lo ∈ {-2.5..2.0} 步长 0.5），高度仍随机 1.1–2.0m。网格吸附顺带消除了浮点误差（0.25 的倍数是精确二进制数），且障碍物与地垫拼块视觉对齐。
- `models.js` 无需改：`createObstacleMesh` 的尺寸完全从碰撞箱派生，自动跟随。
- 验证：多种子单元测试（尺寸/边界/起飞点避让/间距）全部通过；CDP 直连截图确认视觉效果。
- 教训：`agent-browser` CLI 的 daemon 会卡死（陈旧 pid/port 状态文件在 `~/.agent-browser/default.*`），但底层 Chrome 其实已启动且 CDP 端口可从各 `%LOCALAPPDATA%/Temp/agent-browser-chrome-*/DevToolsActivePort` 读出。绕过方案：用 Node 22 原生 WebSocket 直连 `ws://127.0.0.1:<port>/devtools/page/<id>`（页面列表从 `http://127.0.0.1:<port>/json/list` 获取），Runtime.evaluate + Page.captureScreenshot 即可。清陈旧状态文件需提权（HOME 目录沙箱保护）。
