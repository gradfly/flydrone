=== Quick Start Commands ===

First, make sure src/ is on your PYTHONPATH or the package is installed:
  pip install -e ".[vision]"

  # Browser demo (no install needed, runs same MiniFly circuit):
  https://spikecalls.github.io/FlyDrones/

  # Simulated bedroom + scripted hand gestures, LIVE dashboard:
  python -m flydrones demo --live

  # Record the demo as an animated GIF:
  python -m flydrones demo --record my_demo.gif

  # Poke every input group and watch the descending neurons:
  python -m flydrones inspect

  # Swarm mode: one connectome, three independent pilots:
  python -m flydrones swarm --live

  # Benchmark speed on your CPU:
  python -m flydrones bench

  # Use the REAL 166k-neuron MaleCNS connectome (~1.2 GB download):
  pip install -e '.[data]'
  flydrones download malecns
  flydrones build-brain --out data/malecns_brain.npz
  flydrones calibrate --brain data/malecns_brain.npz --out readout_malecns.json
  flydrones demo --brain data/malecns_brain.npz --config configs/malecns.yaml

=== Key Project Directories ===
  src/flydrones/            - main Python package
    brain/brain.py          - Brain class (connectome + LIF + groups)
    brain/synthetic.py      - build_minifly() ~850-neuron stand-in
    brain/lif.py            - LIFNetwork: event-driven spiking simulator
    senses/retina.py        - Retina: optic flow + looming (numpy LK)
    senses/encoder.py       - InputEncoder: features -> Poisson rates
    motor/decoder.py        - MotorDecoder: DN rates -> stick commands
    drones/sim.py           - SimDrone: bedroom + ray-cast camera
    drones/tello.py         - DJI/Ryze Tello backend
    drones/crazyflie.py     - Crazyflie 2.x backend
    drones/mavlink.py       - ArduPilot / PX4 backend
    cli.py                  - `flydrones` command line
    defaults.yaml           - all default parameters + biases
  configs/                  - per-drone YAML config overrides
  examples/                 - usage example scripts
  tests/                    - pytest test suite
  docs/                     - ARCHITECTURE, SCIENCE, GUIDE, HARDWARE, SAFETY
  firmware/esp32_msp_bridge - ESP32 Wi-Fi -> Betaflight/INAV MSP bridge
